你的大脑，一台每天骗你两百次的机器

File 01 — 6 Cognitive Biases

① 偏差画廊：6 个代代相传的大脑 Bug

下面 6 个偏差，全都不是"你笨"，而是大脑为了省电而写进默认设置里的快捷方式。 快捷方式在草原上救过你祖先的命，在考场上会把你坑得很惨。

小枢（本所唯一研究员，也是唯一研究对象）
这 6 个偏差我全都有。而且我刚做完一份「我有没有确认偏误」的自测——结果完美印证了我的假设，所以这题不用改了。
这就是确认偏误本人
FILE 01confirmation bias

确认偏误Confirmation Bias · Wason (1960)

正经

人倾向于搜集支持自己已有想法的信息，而回避、忽略能推翻它的证据。Wason 的「2-4-6 任务」里，被试大多只提出符合自己假设的数列（如 4-6-8）去验证，几乎没人试着去证伪。

现场

你搜「咖啡对身体好」和「咖啡对身体不好」，会得到两个都很有道理的世界。搜索引擎没变，变的是你输入的字。

胡说

「我不是固执，我只是在我的证据库里做了很严格的关键词筛选。」

可用之处：写完任何观点，强制自己找 3 条反例；辩论前先复述对方最强的论点，而不是最弱的那个。
FILE 02anchoring effect

锚定效应Anchoring · Tversky & Kahneman (1974)

正经

先出现的数字会像锚一样拉住你的判断。实验里被试先看转盘随机停在 10 或 65，再估计「非洲国家在联合国中的占比」——两组估计中位数约为 25% 与 45%。一个明知无关的随机数，就拉动了答案。

现场

「原价 ¥999，现价 ¥399」——999 不是价格，是锚。它存在的唯一目的，就是让 399 显得像白捡。

胡说

「我没被锚定，我只是恰好觉得那个随机数很有道理。」

可用之处：谈价、面试薪资、任何谈判——先开口的人定锚；买东西前先写下你独立估的价，再去看标价。
FILE 03survivorship bias

幸存者偏差Survivorship Bias · 二战统计研究小组 / Wald

正经

二战时统计返航飞机的弹孔，发现机翼中弹多、发动机中弹少。Abraham Wald 指出：该加固的恰恰是没弹孔的地方——因为发动机被打中的飞机根本飞不回来，压根没进统计表。

现场

「某某大佬每天只睡 4 小时」——你听到的是活下来的那一个。同样只睡 4 小时、后来进医院的人，没有接受采访的机会。

胡说

「我采访了 100 个成功人士，他们全都坚持努力。所以努力等于成功。」（样本里 0 个失败者，因为失败者不给采访）

可用之处：看到「成功经验」时，先问一句——失败的那批人去哪了？他们做了同样的事吗？
FILE 04barnum / forer effect

巴纳姆效应Barnum / Forer Effect · Forer (1949)

正经

含糊、普适、正反都沾的人格描述，会被大多数人认为「特别像我」。Forer 给全班发同一份性格分析，学生评分平均约 4.26 / 5，认为准确度极高。

现场

「你外表随和，内心其实很在意别人的看法，偶尔会怀疑自己。」——这句对 90% 的人类都成立，包括正在点头的你。

胡说

「星座说我这周会遇到一个改变我人生的人。」（这周你确实遇到了很多人，其中一个是食堂阿姨）

可用之处：判断一份测评靠不靠谱，看它敢不敢说能被证伪的话；全是「既…又…」的描述 ≈ 没有信息量。
FILE 05zeigarnik effect

蔡格尼克效应Zeigarnik Effect · Zeigarnik (1927)

正经

蔡格尼克发现，服务员对尚未结账的订单记得特别清楚，结完账就忘。在实验中，被中断的未完成任务，回忆率高于已完成任务。

诚实

先说清楚：这个效应的后续复现并不稳定，受「被打断的方式、是否有奖励、任务类型」影响，不能当成「没做完就一定记得更牢」。它常被用来自我管理，但请当启发式技巧，不是铁律。

胡说

「我不是拖延，我是故意把作业留到一半——这是基于 1927 年实验的高效记忆法。」

可用之处：写不下去时故意停在句子中间收工，第二天开头会顺得多。但真正影响完成的，还是任务价值和你的习惯。
FILE 06foot-in-the-door

登门槛效应Foot-in-the-door · Freedman & Fraser (1966)

正经

先答应一个小请求，之后更难拒绝大请求。实验中，先被请求签署一份安全驾驶请愿书的人，后来同意在自家院子立起巨大告示牌的比例，比直接提大请求的对照组高得多（常被引用的数字约为 17% → 76%）。

现场

「帮我点个赞就行」→「帮我转发一下」→「帮我写个作业」→「帮我把这门课也修了」。请求是一级一级长出来的。

胡说

「我不是不好意思拒绝，我是在维护第一次答应之后的人格一致性。」

可用之处：培养习惯就用它——把目标切到「两分钟能做完」的版本先启动；反过来，别人想用这招时你能认出来。
File 02 — Playable Experiments

② 实验台：当场被自己的大脑坑一次

光看结论不会让任何人真的相信。下面三个实验都用经典范式改造，你亲手点，数据当场出。 样本量 = 1（也就是你），结论仅供体验，不能当研究数据——这句话很重要。

实验一 · 色词干扰

Stroop, 1935 20 试次 · 约 60 秒

屏幕上会出现一个表示颜色的字。请点「字所显示的颜色」，不要点「字的意思」。 比如屏幕上是绿色的「红」字，你该点「绿」。

准备好了吗？

点下方「开始实验」，共 20 题，越快越准越好

—一致条件平均(ms)
—不一致平均(ms)
—干扰量(ms)
—正确率

为什么会慢？读字是你练了十几年的自动化过程，几乎不耗注意力；而给颜色命名要慢一步。 当两者冲突，自动化过程会抢答，你必须在最后关头把它按下去——这零点几秒的延迟，就是「干扰量」。
要诚实说：这是经典范式（Stroop, 1935），但单次 20 题、样本=1，个位数毫秒的差异纯属噪声，不要解读为「我的注意力有问题」。 它更不适合用来诊断任何东西。

实验二 · 一个随机数字能拖动你多少

Tversky & Kahneman, 1974 2 轮 · 约 40 秒

转盘正在旋转……结果：

—

这个数字和接下来的问题毫无关系。真的。

非洲国家在联合国成员国中所占的百分比大约是多少？

拖动滑杆给出你的估计（0–100）

50%
—本次看到的锚
—你的估计
—两种锚下的差值

原始实验怎么说：Tversky 与 Kahneman（1974）先让被试看一个随机转动的转盘， 转盘停在 10 或 65，然后问同一个问题——「非洲国家在联合国中的占比」。结果：看到 10 的那组估计中位数约 25%， 看到 65 的那组约 45%。一个被试自己都知道无关的数字，把答案整体拉动了约 20 个百分点。
机制：锚定与调整（anchoring and adjustment）——人从一个起点开始调整，但往往调整得不够就停手了。
要诚实说：本页只保留该实验这两个中位数结论，不给其他数字；你玩到的两次差值样本量为 2，别当结论。

实验三 · 哪条线更长？

Müller-Lyer, 1889 约 10 秒

看下面两条线段，凭直觉判断：哪一条更长？

你的直觉选哪条？

真相：两条线实际长度完全相同（各 280 像素）。箭头方向改变了你的知觉，而不是线本身。
机制：一种解释是「深度线索」——向外的箭头像是房间的墙角（远端），大脑自动把远处的物体「放大」补偿， 于是它看起来更长。这至今仍有争论，别把它当定论。
有意思的补充：Segall、Campbell 与 Herskovits（1966）发现，来自不同视觉环境（如是否生活在开阔平原）的人群， 错觉强度并不相同。也就是说，「眼睛看到什么」也会被成长经验影响。
File 03 — Fact Check

③ 辟谣科：那些被玩坏的心理学家

这一节是本页最正经的部分，也是最重要的一节。 心理学是被"科普段子"毁得最惨的学科之一——很多流行说法要么被夸大，要么被完全说反。 所以本节不开玩笑：只讲研究实际发现了什么、以及它不意味着什么。

下面 6 条如果你全信过——放心，我也是。
但今天之后，请至少记住一句：「某个效应存在」不等于「它能解释你的人生」。
本节严肃程度：100%

「普通人的大脑只用了 10%。」

事实：没有证据支持。功能成像研究显示，人在一整天中几乎所有脑区都会被用到，包括睡眠时。这个说法更像是早期对「神经可塑性」等概念的通俗化误传，而不是任何研究结论。

结论依据：现代神经影像学的普遍共识；该说法无原始研究出处

「达克效应 = 越蠢越自信，低能力者都盲目自信。」

事实：Kruger & Dunning（1999）发现的是——在特定任务上表现较差的人，倾向于高估自己的相对水平，部分原因是他们缺少判断「什么算做得好」的元认知能力；同时，高水平者也会略微低估自己。它不是智力等级的判决书，更不是用来嘲笑他人的工具——把它当成「嘲笑工具」，恰恰是它最被滥用的方式。

Kruger & Dunning (1999), JPSP

「棉花糖实验证明：童年的自控力决定你的一生。」

事实：Mischel 等（1972）的原始研究样本很小（斯坦福幼儿园的孩子，几十人规模）。后来 Watts、Duncan 与 Quan（2018）用近千人的大样本复现，发现一旦控制家庭社会经济背景，延迟满足与后来学业成绩的关联大幅减弱。它仍然是个有趣的实验，但不足以「预言人生」。

Mischel, Ebbesen & Zeiss (1972)；Watts, Duncan & Quan (2018), Psych. Science

「多巴胺就是快乐分子，刷手机是在疯狂分泌快乐。」

事实：多巴胺更接近「想要」（wanting）而不是「喜欢」（liking）。它在动机与追求系统里作用突出，而主观的愉悦体验还牵涉其他系统（如μ-阿片等）。这正好解释了一个常见现象：你一直想刷，但刷完并不觉得快乐。

Berridge & Robinson (1998) 等关于 wanting / liking 的研究

「你是左脑型 or 右脑型？理性 or 创意。」

事实：对静息态功能连接的分析并未发现「左脑更发达或右脑更发达」的个体差异模式。左右半球在功能上确实有偏侧化（如语言更多依赖左半球），但这是功能分工，不是「左脑型人格」。你两个半球都在用，而且靠胼胝体一直在交换信息。

Nielsen et al. (2013), PLoS ONE

「我是视觉型学习者，用图画学才有效，你听录音是白听。」

事实：Pashler 等（2008）系统审查了「学习风格匹配教学」的证据，结论是：几乎没有证据表明按学生自诉的学习风格匹配教学方式能提高成绩。绝大多数人其实同时受多种方式影响；真正影响学习效果的，更多是练习方式（如提取练习、间隔复习）而非「风格匹配」。

Pashler, McDaniel, Rohrer & Bjork (2008), Psychological Science in the Public Interest

File 05 — Method & Sources

⑤ 方法说明与参考资料

这一节写给老师和评委看：这份成果是怎么做的、数据怎么用、以及它在哪些地方不严谨。

本页做了什么

  • 选题：认知偏差与社会心理学中可验证的经典效应，共 6 项。
  • 呈现：为降低阅读门槛，对每个效应做「正经解释 / 现场案例 / 一句话吐槽」三段式拆解；吐槽仅作记忆锚点，不作为结论。
  • 互动：将 3 个经典实验范式改造为可现场操作的网页实验，让读者亲自观察到效应。
  • 数据：通过页面问卷收集匿名自评数据，用于分析「不同年级/不同偏差倾向之间是否存在关联」。
  • 技术：单文件 HTML，无外部依赖、无第三方追踪脚本，可离线打开。

这份成果的局限（必须说清）

  • 样本偏差：问卷主要通过同学/社群传播，属于便利抽样，不能代表任何总体。
  • 自评量表的通病：8 道题是课后自编的倾向性题目，用于体验与讨论，不是标准化心理量表，未做信效度检验，不具诊断功能。
  • 相关≠因果：即便发现「高一学生 Q2 得分更高」，也无法推断是年级造成的。
  • 页内实验样本量 = 1：实验区仅用于让读者亲身体验效应，其输出不是研究数据，不纳入统计。
  • 已知争议：蔡格尼克效应等的复现稳定性存在争议，本页已逐处标注，未把争议结论写成定论。

关于数据与隐私

  • 问卷不收集姓名、手机号、位置等可识别信息；昵称与年级均为选填。
  • 页面内的自评版作答默认只保存在你自己的浏览器（localStorage），除非你主动点「提交」。
  • 提交目标（第三方表单平台或自建接口）由页面顶部的配置区决定，可随时改成你自己的地址。
  • 所有数据仅用于本次研究性学习的统计分析，不做其他用途。

  • 配色采用青绿主色（#39C5BB）等常见二次元配色作为致敬——颜色本身不构成版权对象，也不代表与任何作品有关联。
